## 搬瓦工 Fraud 是什么，怎么触发的

搬瓦工后台用的是 WHMCS 系统，这个系统内置一个叫 Fraud Protection 的模块。逻辑很简单：

**你的 IP 地址所在地，和你填写的国家/省份不一致 → 系统判定为欺诈订单 → 自动退款**

就这么一件事。

所以如果你在国内，挂着美国节点的代理去注册，IP 显示美国，然后账号信息里国家又填了中国，两边对不上，Fraud 就来了。反过来也一样——IP 是中国，国家却填的美国，同样触发。

搬瓦工的中国用户量不小，客服对这种情况见怪不怪，但系统的自动判定是没有人情的。触发了就退款，账户也会被标记。

## 搬瓦工注册需要真实填写的信息，到底是哪些

直接给结论，不用猜：

**必须真实的**：
1. **国家（Country）**：如果你人在中国，就选 China。这是最重要的一条，没有之一。
2. **邮箱（Email）**：购买后的密码、账单、工单回复全靠这个收，一定要用能正常收信的邮箱。
3. **下单时的网络环境**：不要挂代理注册，直接用本地网络。你的 IP 要和填写的国家匹配。

**可以不用严格真实的**：
- 姓名：用拼音或英文名即可，不用是真实身份证上的名字。
- 具体地址：只要省份和城市大致对应你的 IP 位置就行，门牌号随便填。
- 电话：区号对（+86）就行，具体号码随意。

说白了，搬瓦工要的是"看起来合理"，而不是和你的身份证完全一致。只要国家、省份大致和你的 IP 地址对得上，基本不会出问题。不过有一条铁律：**不要填得像乱码一样**，比如名字写 "asjkfjskdf"，这种一眼就能看出来是乱填的，客服人工审核时会标出来。

## 如果已经被判 Fraud 了怎么办

不用太慌。

搬瓦工出现 Fraud 的时候会全额退款，钱原路退回，损失只是时间。

处理方式分两步：

1. **先修改账户信息**：登录搬瓦工后台，右上角用户名下拉菜单里选"Edit Account Details"，把 Country 改成 China，手机号改成国内号码格式（+86 开头）。

2. **发工单（Ticket）说明情况**：用英文写一句话就够，大意是"注册时不小心用了代理工具，现在已经改正账户信息，请重新审核"。搬瓦工客服处理速度还可以，一般不会拖太久。

改好之后重新购买，这次直接用本地网络，国家选对，一般不会再触发。

> 顺便提一句：搬瓦工新账户有 30 天内无理由全额退款的政策（满足一定条件，后台直接申请，自动处理），这给了足够的试用空间，买错了方案也不算损失太大。
